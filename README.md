# Himanshi Sharma Portfolio

## Run in VS Code
1. Extract this folder.
2. Open the `himanshi-portfolio` folder in VS Code.
3. Open `index.html` with a browser, OR use the Live Server extension for the best experience.

## Files
- `index.html` - website structure and content
- `style.css` - responsive design and theme
- `script.js` - interactions, counters, certificate modal and theme toggle
- `assets/` - profile photo and certificate images

## Important
GitHub and LinkedIn links were not included as clickable URLs because no profile URLs were provided. You can add your real links in `index.html`.
